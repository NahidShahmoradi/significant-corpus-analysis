# A Corpus-Based Analysis of Significant

## Project Overview
This project examines the adjective *significant* in two genres of the Brown Corpus: News and Learned writing.

## Research Question
How does the semantic use of *significant* differ between News and Learned writing?

## Data
- Corpus: Brown Corpus
- News occurrences: 4
- Learned occurrences: 24
- Total occurrences: 28

## Methodology
1. Identified occurrences of *significant* in the corpus.
2. Examined the surrounding context of each occurrence.
3. Classified meanings as general significance or statistical significance.
4. Compared the categories across genres using Python.
5. Created a visualization using Matplotlib.

## Preliminary Results
- General significance: 22 occurrences (78.6%)
- Statistical significance: 6 occurrences (21.4%)
- News: 4 general-significance cases and 0 statistical-significance cases.
- Learned: 18 general-significance cases and 6 statistical-significance cases.
